# graph-semantics

Complete the semantics of unlabeled variables on a causal graph — and, since 2026-07-28,
discover the graph itself from data.

- **Task 1** — complete the semantics of the unlabeled OBSERVED variables (graph + partial
  labels + data given).
- **Task 2** — Task 1 + translate the LATENT variables into language.
- **Discovery phase (current)** — no given graph: structure comes from RLCD on X alone, then
  the unchanged pipeline completes and translates it.
- (Task 3, later — LLM-scale settings; not in this repo yet.)

Core problem: optimize latent and unlabeled-observed semantic EMBEDDINGS under the causal
constraints derived from the graph. Decoding to language is SpLiCE onto a fixed dictionary
(downstream, not the research core).

## Main line: v6 (finalized 2026-07-28; theory in `v6/THEORY.md`)

```
labels --> e5-large-v2 + LoRA --> term-factory objective  --> WeightNet unrolled --> SpLiCE decode --> judge
           (frozen, v5 era)       (THEORY Def 2, R1-R4)       solve (K=60)           (522k dictionary
                                  gen operator T_theta,                               + CogAtlas terms,
                                  hard-r residual identity                            LoRA-re-encoded)
```

One principle (THEORY §0): a semantic embedding is a geometric realization of the causal
dependence structure. One discipline (§5): every independence statement the graph licenses is
enforced exactly once, in the coordinates the model defines —

| graph relation | claim | channel |
|---|---|---|
| directed edge | child generated by parents | operator: `e_c = Σ T_θ(e_p; sign,|w|,type) + r_c`, `r_c ≡ e_c − ΣT` (hard identity) |
| marginally d-separated | independence | embedding decorrelation to shrink(dcor) targets |
| trek-connected | dependence floor | `|cos| ≥ κ·dcor` on the top quantile |
| d-separated given parents | partial dependence | residual Gram: `cos(r_i,r_j) → signed dcor` |

`T_θ` is Jacobian-locked (additive per-parent = sparsity by construction; `f_neg` inside as
the sign action; zero-init ≡ linear+f_neg; sign audit in training). All constraint-target
MAGNITUDES are nonlinear (distance correlation + gradient-boosted residualization, `nldep.py`);
signs stay Pearson. Trained pair (operator + WeightNet) selected by dev fold-4 MATCH — never
by embedding-space validation loss (measured to decouple).

discovers the structure from X alone; the structure passes downstream UNCHANGED (a V-driven

## Reproduce

1. **Environment**: Python 3.12, `pip install -r requirements.txt` (includes causal-learn
   0.1.4.7 for the discovery phase; `jpype1` optional, only for RLCD's fges stage-1).
2. **Data**: all public — per-dataset sources and the expected `data/` layout are in
   [`DATA.md`](DATA.md).
3. **Trained artifacts** (`v6/outputs/`): four small trained pieces (`negop.pt` f_neg,
   `l3_lora.pt` LoRA, `l2_mlp_v6.pt` WeightNet, `gen_operator.pt` operator) plus the
   re-encoded dictionary (`concept_bank_l3_cog.npz`, ~2 GB) are NOT in git. Two options:
   - retrain from scratch in this order (all on the public data above):
     `v6/negop.py train` -> `v6/tools/l3_train.py` -> `v6/tools/reencode_dict.py` ->
     `v6/tools/expand_dictionary.py` -> `EPOCHS=16 v6/train.py`; the base 521k WordNet+
     Numberbatch bank is built by `v6/tools/build_dictionary.py` (its WordNet-only input bank
     comes from the archived builder — see archive/).
   - or use the released artifact bundle if one is attached to this repository's releases.
   Judged numbers require `OPENAI_API_KEY` + `JUDGE_MODEL=gpt-5.5`; all match/exact numbers
   are free and API-independent.
4. **Determinism**: solver runs are seeded and deterministic within a process; training uses
   fixed seeds but GPU kernel nondeterminism moves epoch-level numbers by ~±.01.

## Metrics

- **judge-ACC (primary)**: decoded words judged by gpt-5.5 against the true label (semantic
  correctness; API failures = missing, never wrong; verdicts disk-cached).
- **match-ACC**: Hungarian assignment of the fold's m predictions to the m true label
  embeddings; fraction assigned to their own label (chance ≈ 1/m; identity, not meaning —
  raw-correlation wins match while losing judge).
- **exact**: nearest neighbour over all labels must be itself.

## Honest notes

- Judge model matters: an unset `JUDGE_MODEL` silently falls back to gpt-4o-mini and produces
  incomparable numbers (measured: .412 vs .752 on identical outputs). The certified numbers
  are gpt-5.5.
- Single-factor scales with direction-critical wording (cfcs class) are the method's weakest
  spot (open item 1); rse-class single-factor scales are fine.
- Discovered-fragment structures can beat published keys on completion while their latents
  translate poorly — prediction-optimal and semantically-true structures diverge; both facts
  are reported, neither is hidden.
- The solver is deterministic within a process; cross-process float noise moves weakly
  constrained directions (riasec class).
- Data: openpsychometrics.org `_rawdata` + TLVD OSF release; nothing under `data/` is
  committed; held-out label texts never enter any training.
